# P&S Infra — Local Website

## Local project path in this workspace
`/mnt/data/PnS_Infra_Website/`

When you download and extract the ZIP on Windows, keep the folder structure intact:

`P&S Infra Website/`
- `index.html`
- `style.css`
- `script.js`
- `START_LOCAL_SERVER.bat`
- `assets/`
  - `pns-infra-logo.png`
  - local SVG illustrations

## Important: do NOT open index.html from inside the ZIP
Extract the ZIP first. Then either double-click `index.html`, or preferably run `START_LOCAL_SERVER.bat`.

The local server option is recommended because it behaves like a normal website and avoids browser restrictions associated with opening files directly.

## Design references researched
The information architecture takes useful, non-copying cues from current Indian construction/workforce websites:
- D.C. Network: combines civil/electrical/underground construction, HR & manpower, and project oversight.
- HARIKON Exponentials: presents integrated engineering + manpower + infrastructure services.
- Manpasand Enterprises: combines civil, infrastructure and manpower capabilities in one execution-oriented site.
- BuildMandi: uses a clear manpower request → match → deploy workflow.
- L&T Construction: uses strong project/capability storytelling for a large infrastructure brand.

P&S Infra's design is intentionally its own: blueprint grid, orange/navy visual system, scope-first messaging, workforce pathway and a four-step execution flow.
