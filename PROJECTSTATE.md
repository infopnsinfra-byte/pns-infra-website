## 3. Design Direction

The website must feel like an international workforce / infrastructure solutions company, not a local contractor template. The current visual system uses deep forest green + warm brass/gold + white/ivory so it remains clearly distinct from SahiRate.

### Photography rule
- Prefer real, documentary-style construction/workforce photography.
- AI-generated imagery should be minimal and should not be used to represent actual P&S Infra projects, workers or clients.
- Final production should prioritize owned P&S Infra photographs.

### Visual language
- Premium corporate
- International B2B
- Clean editorial layouts
- Strong typography
- High-quality workforce photography
- Deep forest green / white base
- Warm brass / champagne-gold accent
- Soft ivory backgrounds
- Subtle engineering/grid details
- Strong whitespace
- Sharp geometry rather than excessive rounded cards

### Must be different from SahiRate
P&S Infra must have its own visual identity:
- No SahiRate-style UI
- No material-price dashboard language
- No marketplace/product-card aesthetic
- No price/trend visual system
- No reuse of SahiRate components unless technically necessary

## 11. Development Rules

- Responsive from mobile-first principles
- Test at 360px, 390px, 768px, 1024px and desktop widths
- No horizontal overflow
- Images must have alt text
- Buttons must have clear actions
- Avoid excessive animations
- Respect reduced-motion preferences
- Keep page performance high
- Use local assets wherever practical
- External images must be replaced with licensed/owned production assets before final launch
- Never expose private credentials in source code
