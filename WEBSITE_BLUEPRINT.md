# D. TYPOGRAPHY

Recommended direction:
- Primary display: Barlow Condensed / similar strong condensed corporate font
- Body: Inter / similar clean sans-serif

Headline characteristics:
- Uppercase
- Strong weight
- Tight line-height
- Selective orange emphasis

Avoid:
- Decorative fonts
- Excessive italic text
- SahiRate's visual language

---

# E. IMAGE DIRECTION

**Real photography first.** AI-generated images are only a fallback for generic visual mood and must not be presented as real P&S Infra work or workforce.

Photography should show:
- Realistic construction sites
- Indian / South Asian workforce where appropriate
- Engineers
- Skilled workers
- General workers
- Supervisors
- PPE
- Blueprints / tablets
- Industrial and infrastructure environments

Avoid:
- Generic office stock photos
- Overly staged corporate handshakes
- Unrealistic AI-looking workers for final production
- Repeated hero image across every page

# F. RESPONSIVE BLUEPRINT

## Mobile 360–430px

Hero:
- Image remains dominant
- Text stacked
- One primary CTA
- Compact slider controls
- No tiny multi-column text

Manpower:
- One card per row
- Strong icons
- Short copy

Process:
- Vertical timeline

Industries:
- 2-column compact grid or horizontal scroll

Form:
- Single column
- Large touch targets

## Tablet 768–1024px

- 2-column content sections
- 2-column manpower cards
- Hero image/text balanced
- Navigation can collapse

## Desktop 1200px+

- Full-width hero
- Editorial split layouts
- 3-column content
- Strong whitespace
- Large photography
- Controlled animation
